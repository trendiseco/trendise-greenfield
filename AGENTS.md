# TRENDISE repository

For completed changes requested in this repository, verify the work, commit only the files belonging to the task, and sync the commit to the private TRENDISE GitHub repository. Preserve unrelated working changes. Leave credentials, local environment files, database exports, and local browser screenshots out of commits.

On the local main branch, the Git post-commit hook pushes to the TRENDISE origin when installed. Confirm that the remote branch includes the completed commit before reporting it as synced. If a push fails, diagnose the problem and use a normal push when possible. Do not force-push.
